## Sobre o projeto

**Nuvio Web** é uma versão web baseada no projeto open source [Nuvio TV](https://github.com/NuvioMedia/NuvioTVSmart).

O objetivo é disponibilizar uma experiência acessível diretamente pelo navegador, sem exigir a instalação de um aplicativo específico para cada plataforma.

Diferentemente de uma aplicação tradicional distribuída em vários arquivos, esta versão é organizada em um único arquivo HTML, reunindo sua estrutura, estilos e funcionalidades.

## Recursos

Entre os recursos presentes na aplicação estão:

| Recurso | Descrição |
|---|---|
| Catálogo | Interface de navegação por conteúdos |
| Busca | Área dedicada à pesquisa |
| Biblioteca | Área para organizar e acessar conteúdos |
| Reprodução | Interface própria de reprodução |
| Legendas | Controles e configurações de legendas |
| Áudio | Painel de configurações de áudio |
| Velocidade | Ajustes de velocidade de reprodução |
| Fontes | Painel de seleção de fontes |
| Configurações | Área de personalização e ajustes |

*Os recursos disponíveis podem depender do navegador, das fontes configuradas e da compatibilidade do dispositivo.*

## Compatibilidade

O Nuvio Web foi desenvolvido para funcionar diretamente em navegadores modernos.

Pode ser acessado em diferentes plataformas, incluindo:

- Android
- iOS e iPadOS
- Windows
- Linux
- macOS
- Outros dispositivos com navegadores compatíveis

**A proposta é simples:** acessar a aplicação pela web, sem depender de um sistema operacional específico.

A disponibilidade de determinados recursos pode variar conforme o navegador e o dispositivo utilizado.

## Tecnologia e estrutura

O projeto utiliza tecnologias web para reunir a aplicação em um único arquivo.

- **HTML:** estrutura da aplicação.
- **CSS:** estilos e apresentação visual.
- **JavaScript:** funcionalidades e interações.
- **GitHub Pages:** hospedagem da versão web.
